## P0 — GAP 1: Auto-seed Nielsen's 10 heuristics at boot
**Mission:** Seed the 10 Nielsen default guidelines at server boot so `GET /api/v1/guidelines` returns them on a fresh DB.
**Verified problem:** `GuidelineRepo.hasDefaults()`/`insertMany()` exist but have **no call site** outside tests, and there is no `DEFAULT_GUIDELINES` constant. The `guidelines.routes.ts` "seeded by the composition root" comment is currently false; fresh/prod DB returns an empty catalogue.
**Affected files:** NEW `server/src/domain/guideline/DEFAULT_GUIDELINES.ts`; `server/src/composition/container.ts` (idempotent seed in `start()`).
**Acceptance criteria:**
1. Module exports exactly the 10 canonical Nielsen heuristics, `isDefault: true`.
2. Boot calls `hasDefaults()`, inserts once when false, idempotent across restarts.
3. Integration test on real Postgres: fresh boot → 10 defaults; second boot → no duplicates.
4. The false route comment now matches reality.
**Severity:** High · **Effort:** S (0.5–1d)

## P1 — GAP 2: Unit tests for 9 under-tested UI modules
**Mission:** Bring untested UI modules to the project's "every component tested" norm.
**Modules:** pages `IntegrationsPage, ClientPortalPage, WorkflowsPage, ReportingPage, OnboardingWizard, NotFoundPage`; components `ReplayPlayer, HeatmapOverlay, NotificationBell`; extension `ScreenshotViewer`.
**Acceptance criteria:**
1. Each gets mount/render + primary interaction + empty/error-state coverage.
2. `ReplayPlayer` drives playback over sample `ReplayEvent[]`; `NotificationBell` asserts unread badge + mark-read; `HeatmapOverlay` asserts cell rendering.
3. `npm test` green; no new vitest exclusions; no production-code changes.
**Severity:** Medium · **Effort:** M (2–3d)

## P1 — GAP 3: Unify list-collection pagination envelopes
**Mission:** Give every GET-collection endpoint the shared `{ data, pagination }` envelope.
**Verified problem:** Paginated: projects, annotations, teams, comments, activity, auditLog, webhooks(list). Bare keyed objects: `workflow`, `premium`, `clientPortal`, `guidelines`, `billing`, webhooks `{deliveries}`.
**Affected files:** `server/src/adapters/inbound/http/{workflow,premium,clientPortal,guidelines,billing,webhooks}.routes.ts`; reuse `shared/src/pagination.ts`; update dashboard/extension consumers.
**Acceptance criteria:**
1. Every GET-collection returns `{ data, pagination:{page,pageSize,total,totalPages} }` via shared helpers.
2. No bare array, no ad-hoc keyed object.
3. Route tests assert envelope + honored `page`/`pageSize`; clients updated and shipped together.
**Severity:** Medium (breaking shape — server+client ship together) · **Effort:** M (1.5–2d)

## P1 — GAP 4: Local email sink (+ optional monitoring profile)
**Mission:** Add a local SMTP catcher (mailhog/mailpit) so dev can observe emails; optional metrics behind a compose profile.
**Verified problem:** `docker-compose.yml` has db/migrate/redis/api/dashboard only — no SMTP sink, no local observability. `config.smtp` is already consumed via `nodemailer`.
**Affected files:** `docker-compose.yml` (mail service 1025/8025, SMTP env on `api`, prometheus/grafana under `profiles:[monitoring]`); `README.md`.
**Acceptance criteria:**
1. Mail-catcher added; `api` SMTP points at it; a dev verification email lands in its UI.
2. Monitoring behind a profile; default `up` does not start it.
3. `docker compose up` boots clean; README documents the mail UI URL.
**Severity:** Medium (dev-experience) · **Effort:** S–M (1d + 1d)

## P2 — GAP 6: Push heatmap bucketing into SQL (defer monolith splits)
**Mission:** Move heatmap density aggregation into a Postgres `GROUP BY`.
**Verified problem:** `heatmap.routes.ts` selects all matching rows into Node and buckets in JS (`TODO(perf)`). `heatmap.utils.ts#bucketIntoHeatmapCells` is the tested oracle. Bounded by live `statement_timeout = 30000`, so non-urgent.
**Acceptance criteria:**
1. Density via Postgres `GROUP BY floor(x/:cell), floor(y/:cell)`; output matches `bucketIntoHeatmapCells` (parity/property test) + integration test.
2. (Deferred) `Popover.ts` (~113KB; **has** `Popover.test.ts`) and `index.html` (~87KB) splits only if size becomes demonstrated friction, test-guarded, template IDs preserved.
**Severity:** Low–Medium · **Effort:** heatmap S; splits L (deferred)
**⚠️ Complexity flag:** do heatmap SQL now; the big-file splits carry regression risk for maintainability-only payoff — schedule separately.

## P2 — GAP 7: Converge the error-response envelope (no re-architecture)
**Mission:** Finish convergence onto the canonical `{ error:{code,message,details} }` in `errors.ts`.
**Verified residue:** per-file `sendError()` in `billing.routes.ts:7` & `premium.routes.ts:13`; `.flatten()` vs `.flatten().fieldErrors` inconsistency (`billing:47`, `bulk:25`, `triage:44`); bare-string `error:` at `annotations.routes.ts` (~420), `projects.routes.ts:308`, `guestFeedback.routes.ts:79-80` (last also emits flat top-level `issues`).
**Acceptance criteria:**
1. All validation errors flow through one shared helper; `details.issues` standardized.
2. Route test documents the single canonical envelope; no bare-string `{error:"..."}`, no flat `issues`.
3. Per-file `sendError` deleted in favor of shared.
4. **No hexagonal extraction of thin-CRUD routes** (ADR-006 Accepted) — out of scope.
**Severity:** Low · **Effort:** S (0.5d)

## P2 — GAP 8: Theme-token premium-page dynamic content
**Mission:** Replace hardcoded hex + inline `style.cssText`/`innerHTML` in premium pages' *dynamic* content with `@pinpoint/shared/theme` tokens.
**Verified problem (corrects prior pass):** page shells already use `cloneTemplate`+`signal()`; only *dynamic* content hardcodes styles — `IntegrationsPage.render()`, `ReportingPage.buildBarSpark()` + team list, `ReplayPlayer` ripple (all with `#4f46e5` etc. that duplicate `SEVERITY_COLORS`/theme).
**Acceptance criteria:**
1. No hardcoded brand/severity hex literals; colors read from `@pinpoint/shared/theme`.
2. Dynamic content built via DOM/templates, not inline-`style` `innerHTML`.
3. Visual output unchanged; GAP 2 tests still pass.
**Severity:** Low · **Effort:** S (token-only); +1–2d full migration (not recommended standalone)
**⚠️ Complexity flag:** do the token swap only; skip the full template/CSS-module migration unless touching these pages for GAP 2/3.

- **Knex `statement_timeout`** — `container.ts` `SET statement_timeout = 30000` in `pool.afterCreate`.
- **Analytics cache invalidation on write** — `annotations.routes.ts` calls `invalidateCache` on mutate.
- **Local Redis** — `docker-compose.yml` `redis:7-alpine` + `REDIS_URL`.
- **CD pipeline** — `.github/workflows/deploy-production.yml` + `deploy-staging.yml`.
- **Session Replay "stubs"** — `ReplayPlayer.ts` is a complete RAF playback component; only its test was missing (folded into GAP 2).
- **Thin-CRUD vs hexagonal split** — Accepted in ADR-006; do not re-architect.
