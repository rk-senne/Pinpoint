# Building the Pinpoint Firefox add-on from source

This archive is the complete source of the Pinpoint monorepo. The add-on
(`pinpoint-firefox-<version>.zip`) is the output of the `extension`
workspace; the other workspaces are only needed because npm resolves them as
one lockfile.

## Environment

- Node.js 20 LTS or newer (built and verified with Node 22 and Node 26),
  npm 10+. Any OS; no native toolchain is required.
- Network access to the npm registry (for `npm ci`).
- The `zip` command (only for the packaging step).

## Build

From the archive root:

```bash
npm ci                                              # exact versions from package-lock.json
npm run build --workspace @pinpoint/shared          # workspace dependency (tsc)
npm run build:firefox --workspace extension         # vite build + Firefox manifest transform
```

Output: `extension/dist-firefox/` — this directory is exactly the content of
the uploaded add-on zip (`manifest.json`, `assets/`, `icons/`, `options/`,
`popup/`, `src/`, `service-worker-loader.js`).

To also produce the zip (`extension/artifacts/pinpoint-firefox-<version>.zip`)
with the same tool the submission used (web-ext 10.8.0):

```bash
npm run package:firefox --workspace extension
```

The bundle is built by Vite/Rollup with `@crxjs/vite-plugin`; the
`extension/scripts/firefox-manifest.mjs` step rewrites the generated Chrome
manifest into a Firefox one. No code is generated by any other tool.

## Build-time configuration

`VITE_PINPOINT_API_ORIGIN` (default `http://localhost:3001`) is baked in as the
default Server URL; the submitted build used the default.

## Reproducibility

File *contents* are reproducible. Zip container bytes differ run to run
(web-ext records file modification times), so compare extracted files, e.g.
`diff -r <your dist-firefox> <unzipped submission>`.
